## 2. 实测与自查中的修正

- 审查者 2 关于附件列表的说法，核实后有修正：连接条件本身已限定同帖，问题在于开放判定沿用了 gate id，因此修复方式是「关联不上即锁定」，而不是补连接条件。
- 审查者 1 认为编辑路径的加锁顺序与状态迁移相反。核实后确认：编辑原先是「主题 → 版块 → 帖子」，状态迁移是「主题 → 帖子 → 版块」。去掉纯编辑的版块锁后，两者在有状态变化的路径上统一。
- 审查者 5 对 GIF 与签名的判断在核实后成立；对 `bio` 的判断不成立（不纳入）。
