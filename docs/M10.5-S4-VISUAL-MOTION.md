## 1. 质感决策表（视觉一致性）

| 维度 | 决策 | 令牌 |
|---|---|---|
| 整体气质 | **现代克制**：细边框 + 极浅阴影的双层卡片；不做浮雕/拟物/重玻璃 | — |
| 圆角 | 卡片/弹层 `12px`（现网 --radius 基准，保持）；按钮/输入 `10px`（radius-md）；胶囊/头像全圆；对话气泡 `14px` 且发送侧右下角 `4px` | --fw-radius-md/lg、--radius |
| 阴影分层 | 三级海拔：静止卡=shadow-1（1px 细影）；hover/悬浮=shadow-2；弹层/抽屉=shadow-3。暗色主题由语义层加深（现网机制） | --fw-shadow-1/2/3 |
| 边框策略 | 卡片恒有 1px border（--border）；hover 抬升 = border 加深 + shadow-2 + translateY(-1px)；**只动 transform/box-shadow** | --border |
| 玻璃（backdrop-blur） | 仅用于顶栏、移动端底部 Tab，以及对话页吸顶头和吸底输入区；卡片、列表、正文内容区不玻璃化 | — |
| 按压反馈 | 所有可点元素 active:scale-[0.97]，150ms（Button 基类已全局生效；可点卡片行同款） | --fw-dur-fast |
| focus | 现网 ring 体系不变（focus-visible ring-3） | --ring |
| 图标 | lucide 线性统一（已引入），线宽默认 2；功能色不染色（中性前景，语义位才用色） | — |

## 2. 动效令牌（已落 primitives.css 尾部；Tailwind 工具类映射见 globals @theme inline）

| 令牌 | 值 | 用途 |
|---|---|---|
| --fw-dur-fast | 150ms | L1 微交互（按压/开关/色变） |
| --fw-dur-base | 250ms | L2 常规淡入位移、弹层 |
| --fw-dur-slow | 400ms | L2 页面级方向性过渡 |
| --fw-dur-spring | 500ms | L3 过冲回弹、扩散打开 |
| --fw-ease-out | cubic-bezier(0.22,1,0.36,1) | 进场：加速度切入缓停 |
| --fw-ease-inout | cubic-bezier(0.65,0,0.35,1) | 对称位移 |
| --fw-ease-spring | cubic-bezier(0.34,1.56,0.64,1) | 刹车过冲回弹（站长「滑动过一点弹回来」） |
| --fw-ease-exit | cubic-bezier(0.4,0,1,1) | 退场加速离场 |

工具类：`ease-out-soft / ease-spring / ease-exit / ease-inout`；进场类 `.fw-enter`（globals.css）+ `animationDelay` 做 stagger。
**纪律**：页面/组件不得裸写 `cubic-bezier|ms`——一律引令牌；只动 `transform/opacity/clip-path`；`will-change` 仅限进行中的过渡。

## 3. 四级动效体系

### 3.1 L1 微交互（fast 150ms）
按压 scale 0.97（Button 基类已生效）；hover 抬升（可点卡片行）；开关/勾选弹跳（spring）；Tab 指示器滑动；
点赞飞出/数字滚动（S5 逐个接）。原则：**反馈即时、位移 ≤2px、不抢内容**。

### 3.2 L2 页面级方向性过渡（slow 400ms）
- **前进 = push**：新页自右 28px 切入（透明度 0.6→1）；**返回 = pop**：自左切入——站长「左切进入、右切返回」。
- **接线方式**：`withViewTransition(() => router.push/href 导航, "push" | "pop")`。判定前进/返回：S5 在导航层做层级表
  （路由深度：首页 0 < 列表 1 < 详情 2；Tab 间=fade）。桌面同款但位移减半（克制），或仅淡入。
- 载体：View Transitions API（same-document）。`html[data-vt]` 选型 + globals.css 关键帧已就位。

### 3.3 L3 触点扩散打开（spring 500ms）
卡片/封面 → 详情：`captureTransitionOrigin(e.clientX, e.clientY)` 后 `withViewTransition(update, "expand")`——
新视图以点击坐标为圆心 clip-path 圆形展开（--vt-x/--vt-y）。适用：内容流卡片→主题页、图片→放大查看。
降级：不支持 VT API / reduce → 直接切换。演示见 /design/motion。

### 3.4 L4 进场编排（base 250ms × stagger 50ms）
列表**首屏**错落切入（`.fw-enter` + animationDelay=i×50ms，封顶 10 项）；翻页/加载更多**不重播**；
弹层内容组 stagger 可选。原则：编排只服务首印象，不做持续动画。

## 4. 无障碍与降级（硬性）

- `prefers-reduced-motion: reduce`：.fw-enter 与全部 view-transition 动画归零（globals.css 已配）；
  withViewTransition 直接执行更新；L1 按压/色变保留（不涉及位移）。
- 兼容性：VT API 仅 Chromium/Safari 18+；不支持时一切交互**同步可用**（助手直接调 update）。
- 弹层/抽屉（Radix + tw-animate-css）沿用现网动效，时长在 S5 对齐到令牌（改 tw-animate 引用处，不换库）。

## 5. 技术路线（定稿）

1. **不引 motion 库**：CSS 令牌 + tw-animate-css + 手写 VT 助手（`src/lib/motion/view-transition.ts`，已落）。
2. React `<ViewTransition>`（React 19 已内置）待 Next 稳定暴露配置后再评估迁移，接口形态已与本助手对齐。
3. 落地映射（S5 执行清单）：
   - 路由层：方向判定表 + push/pop 接线（一处封装，全站生效）；
   - 组件层：可点卡片行 hover 抬升、气泡圆角、Sheet/Dialog 时长对齐令牌、骨架屏复用页面布局（S2 states.html）；
   - 页面层：内容流卡片 expand（3.3）、列表首屏 stagger（3.4）、空态/错误态配 S2 图例。

## 6. 验收口径

- /design/motion 演示页四级全部可玩且 reduce 降级正确；
- 全站无裸写时长/曲线（review grep `cubic-bezier(\d` 白名单=令牌文件与 tw-animate 内部）；
- 动效不引入新依赖、不阻塞交互（点击响应 ≤100ms 内有视觉反馈）。
