- **阶段一·骨架（M1–M5.5）**：工程基线 + 模块内核 + 数据只读可见 + 账号体系 + 权限内核 + **数据模型/迁移重构（M5.5）**。完成标志：一个游客能在真数据上浏览论坛（受限内容零泄露），登录与权限链路贯通，门控与积分抽象就位。

- **阶段三·完善与上线（M9–M13，含 M10.5）**：管理后台、外围功能、**全站 UI 视觉打磨（M10.5）**、主题包/PWA、安装向导与零数据部署、生产部署与老用户召回。完成标志：社区重启。**✅ 已达成：2026-11-08 正式切换上线，2026-11-09 M13 收口、进入观察期。**
