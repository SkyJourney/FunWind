## 需求

1. 后台新增「站点管理」分组 + 「LOGO 管理」独立菜单项（版主以上，建议新权限点 `admin.site`）。
2. **LOGO 池**：可上传多枚 LOGO（名称/备注、启用标记），支持随时切换当前生效项——
   运营场景：节日（圣诞/新年）、动漫联动日、日常轮换；与 M11 主题包里程碑天然配合
   （主题包可声明默认 LOGO 池成员）。
3. 前台消费点：顶栏品牌位（现为 Wind 图标占位，site-header.tsx:44）+ 页脚（未来）；
   渲染 `<img src="/files/...">`，走既有附件存储（files 表 + gc 管线），高度锁 28px（顶栏）。

## 设计要点（实施时依此展开）

- 存储：复用附件管线（STORAGE_DIR + /files/[...key]）；site_settings 新键
  `site.logo.active`（fileKey）与 `site.logo.items`（池清单 JSON，元数据不含二进制）。
- 切换即生效：走 site-chrome 既有 TTL 缓存（30s）+ 管理保存后 invalidateSiteChrome()。
- 管理页形态（S2 后台线稿模式）：池卡片网格（当前项高亮 + 「设为当前」/「停用」）+ 上传入口
  （拖拽区 + 进度条，B2 编辑器线稿同款）；删除需二次确认（Dialog）。
- 默认态：池为空或未启用时回退 Wind 图标占位（零数据部署友好）。
- 权限：`admin.site` 新权限点（authz 词汇表扩充，默认授予 admin 角色）；菜单显隐照 admin.* 派生。
- 测试：site-chrome 读写、切换生效、无 logo 回退、权限 404；E2E：上传→设为当前→顶栏呈现。
