# M3 · 内容只读渲染

- 阶段：一·骨架 ｜ 覆盖模块：M01（读路径）/ M04 ｜ 依赖：M2
- 状态：⬜ 未开始

## 目标

把已迁移的真实数据渲染出来：游客可完整浏览版块、帖子、楼层。这是数据迁移价值的第一次兑现，
也是后续一切交互功能的舞台。

## 范围（做什么）

1. Drizzle 查询层：forums（树形/排序/is_show）、threads（列表/详情/spam 过滤/置顶精华）、posts（楼层/嵌套回复）。
2. 页面：首页（版块目录 + 置顶/最新聚合）、版块页（主题列表 + 分页 + 主题分类 topic_type 筛选）、
   帖子详情页（楼主正文 + 楼层列表 + 嵌套回复展示 + 楼层锚点 `#p{pid}`）。
3. 渲染管线：`content_md` → 净化（白名单标签）→ 服务端渲染；表情图 `/emotion/**`、附件下载 `/attachment/**`
   静态路由直指旧目录（Next rewrite 或独立路由 handler）。
4. 数据状态呈现：`is_spam` 默认不可见、`status` 屏蔽位、孤儿作者「已注销」、已售帖/隐藏块的占位提示（M6 前不可购买）。
5. URL 定稿：`/f/{fid}` 版块、`/t/{tid}` 帖子、分页 `?page=n`——301 映射表在 M12 依赖此格式。
6. 移动端适配第一版（列表单列、详情楼层次导航）。

## 边界（明确不做什么）

- 不做发帖/回帖/编辑（M6）；不做登录态下的任何差异视图；不做搜索/标签/点赞（M8）。
- 不做投票渲染（M10）；不做回收站/审核界面（M9）。
- 全文检索不做（MySQL LIKE 兜底仅限详情页内楼层定位，不暴露站内搜索入口）。

## 测试规则

- 组件测试：楼层列表（嵌套回复/锚点）、分页、净化函数（XSS 用例集：script/iframe/javascript: 协议/on* 属性）。
- E2E（真实数据）：游客打开首页→进入『动画 · アニメ』→打开「刀剣乱舞」帖→楼层锚点直达；
  spam 主题不可达（3,033 条抽样直链返回列表页或 404 态）；已注销作者显示。
- 性能：帖子详情/列表 Lighthouse LCP < 2.5s（本地数据基准）。
