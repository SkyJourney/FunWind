# M22 · RSS/Atom 订阅输出（大纲）

- 阶段：四·运营与演进 ｜ 依赖：无（小而独立，可随时插队）｜
  状态：⬜ 已立项（2026-11-16，大纲版）——开工前细化
- 立项动因：站长 2026-11-16 拍板：「类似 RSS 订阅」= **面向读者的 RSS/Atom 内容订阅输出**
  （不是站内推送增强，也不是开放写 API）。

## 目标

1. 为站点内容提供标准订阅 feed：全站最新主题、版块主题、（可选）主题回复。
2. **可见性红线**：只输出游客可读（read_policy=public 且内容 visible）的条目——restricted/会员版块内容零泄露，
   feed 不提供任何认证形态。
3. 摘要生成复用现有净化管线；端点纪律对齐公开只读端点先例（ETag + 缓存 + 不可读一律 404）。

## 1. 已探明事实（2026-11-16）

| # | 事实 | 影响 |

## 2. 范围要点（开工时细化）

1. 端点：`/feeds/latest`（全站最新主题）、`/feeds/forum/[fid]`（版块主题）；`/feeds/thread/[tid]`（回复）可选。
2. 格式：RSS 2.0 与 Atom 双格式（待 D2）；XML 转义与字段映射集中一个构建器（纯函数，可单测）。
3. 内容纪律：只含游客可读条目（标题/链接/作者/时间/摘要）；条目数上限（建议 50）；无翻页。
4. 缓存：ETag + s-maxage（沿用 /api/emojis 纪律）；版块不存在/不可读一律 404（对齐 /p/[pid]）。
5. 发现：前台页头按上下文注入 `<link rel="alternate" type="application/rss+xml">`（全站/版块页）。
6. 测试：XML 结构单测；**泄露测试**（restricted 版块/非 visible 内容断言不出现于任何 feed）；
   E2E 发现链接；Lighthouse 不回退。

## 3. 边界（明确不做什么）

- 不做认证 feed / 私有内容订阅（会员版块内容永不进 feed）。
- 不做全文输出（只摘要+链接，规避转义面与版权面）。
- 不做 feed 集合页/管理后台项；不做 WebSub/ping 与更新推送。
- 不新增 schema（feed 全实时查询 + 缓存）。

## 4. 待站长拍板的决策项

| # | 决策 | 建议与备选 |
|---|---|---|
| D1 | feed 清单 | 建议 latest + forum/[fid] 必做，thread 回复 feed 可选 |
| D2 | 格式 | 建议 RSS 2.0 + Atom 双格式（构建器一处、两壳）；备选仅 RSS 2.0（阅读器兼容最广） |
| D3 | 摘要来源 | 建议 body_md 首段去 Markdown 后截断（净化管线内做）；备选全文（不建议） |
| D4 | 条目数与缓存 | 建议 50 条 + ETag/60s；备选进 site_settings 可配 |

## 5. 门禁基线

verify:all 全绿；XML 构建器单测 + 泄露测试必过；E2E 发现链接与 404 语义；
CHANGELOG；本文档执行记录回写。

## 6. 风险

- **泄露**：唯一高危点——查询层必须按游客视角过滤，集成测试穷举（restricted 版块 / disabled / deleted / pending 内容）。
- **转义/XSS 进阅读器**：所有文本经 XML 转义、摘要经净化管线，禁裸拼。
- **爬虫压力**：缓存 + 条目上限兜底。
