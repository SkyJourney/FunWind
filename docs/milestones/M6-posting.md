# M6 · 发帖与内容生产

- 阶段：二·核心 ｜ 覆盖模块：M01 交互层 ｜ 依赖：M3 + M5
- 状态：⬜ 未开始

## 目标

论坛的「写」路径：MD 编辑器、发帖/回帖/嵌套回复、编辑/删除、草稿、附件上传，
并把事件总线接上真实业务事件——从此模块注册表有了真实生产者。

## 范围（做什么）

1. MD 编辑器：工具栏 + 表情面板（`emoticons` 表驱动）+ 预览 + 移动端适配。
2. 发帖：选版块/主题分类（topic_type）、售帖（SELL，价格与积分联动校验）、隐藏块（HIDE）；
   回帖：楼层追加 + 嵌套回复（reply_to_pid）；@提及触发通知事件（通知中心在 M8，本期仅发事件）。
3. 编辑/删除：编辑时限（旧 post_modify_time 语义）、删除进回收站表（软删）、版主操作带理由（旧 force_operate_reason 语义）。
4. 草稿：自动保存 + 恢复（旧 nw_draft 语义重设计）。
5. 附件上传：本地磁盘存储（沿用 `/attachment` 约定新目录 `upload/`），图片缩略、类型白名单、大小配额（旧 uploads_perday 语义）。
6. 频控落地：threads_perday / post_pertime / post_url_num（M5 条件接口的实现）。
7. 事件接入：`thread.created/replied/edited/deleted`、`attachment.uploaded` 真实派发（写 event_log）。

## 边界（明确不做什么）

- 不做富文本编辑器（MD 为主已是决策）；不做投票帖创建（M10）。
- 不做积分奖励发放（M7 的 credits 模块消费事件）。
- 图片转码/视频处理不做（仅校验与缩略）。

## 测试规则

- 组件测试：编辑器（工具栏插入/表情面板/预览）≥90% 覆盖。
- E2E：发帖→回帖→嵌套回复→编辑→删除（回收站可查）全流程；售帖/隐藏块读者视角占位；
  频控触发限流提示；无权限版块发帖被拒（权限联动）。
- 安全：渲染净化回归（M3 用例集 + 新标签）；上传文件类型伪装拦截用例。
- 性能：发帖接口 p95 < 300ms（本地基准）。
