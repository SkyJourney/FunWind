- 阶段：M10.7 之后、M11 之前的独立里程碑 ｜ 状态：🟡 设计中（待站长确认 §4 的待决项后开工）

- 依据：`docs/milestones/M6.3-editor.md`、`M6.4-uploads.md`、`docs/GATES.md`、`docs/ATTACHMENT-GATES.md`。

## 1. 现状审查（读源码得出，Step 1 再逐项实机复现）

| 现象 | 根因 |
|---|---|
| 所见即所得区没有边框 | `.fw-rich-editor` 在 `globals.css` 没有任何样式，编辑器没有容器外框与聚焦态 |
| 表格是无边框白框、删不掉、不能增删行列 | 只装了 `TableKit`，编辑器内没有表格样式；工具栏只有「插入」，没有表格上下文操作 |
| 工具只有原生 `title` 提示、有的点了没反应 | 原生提示有延迟且触屏不可见；「换行」序列化为单个 `\n`、「分隔线」在空文档里几乎无可见变化 |
| 没有插入图片工具 | `ImagePicker` 在编辑器外面，不是工具栏项 |
| 图片与附件不联动 | 内联图片 `purpose:"inline"` 不进附件面板；删附件不清正文引用，反之亦然 |
| 回复只有页面底部表单 | 没有移动端固定条 |

## 2. 设计

### 2.1 工具栏（Markdown 主流能力补全）

**能力边界取决于站点渲染器**：渲染管线是精简 GFM（只有表格与删除线，见 CLAUDE.md 硬约定 6），所以**不做任务列表、不做自动链接**；工具栏只放「渲染得出来」的语法。

| 分组 | 项 | 说明 |
|---|---|---|
| 文本 | 标题（H1–H3 下拉）· 加粗 · 斜体 · 删除线 · 行内代码 · 链接 · 清除格式 | 链接用小弹层（地址 + 文本），选中文字时直接套链接 |
| 块 | 无序列表 · 有序列表 · 引用 · 代码块 · 分隔线 | 列表支持 Tab 缩进 / Shift+Tab 反缩进 |
| 插入 | **图片** · 表格 · **锁定内容块**（名称待定，§2.4） | 图片见 §2.3 |
| 历史 | 撤销 · 重做 | |
| 右侧 | 切换源码 · 预览 | 与现有外壳按钮合并进工具栏同一行 |

交互规范：
- 全部按钮图标化（`lucide-react`），**即时 Tooltip**（桌面 hover / 聚焦，触屏长按），内容含名称与快捷键（⌘B / ⌘I / ⌘K …）；沿用 `ui/` 已有的 hover 组件，不引新库。
- 移动端：工具栏单行**横向滚动**（不换行占三行），触控目标 ≥ 44px；分组间用细分隔线。
- 去掉「换行」按钮（Shift+Enter 即硬换行，按钮既无反馈又易误解）。
- 无选区时不适用的按钮置灰而不是点了没反应。
- 往返保护不变：序列化仍经现有 `@tiptap/markdown` + 自定义规则；**不新增会改写原文的节点**。

### 2.2 编辑器外观与表格

- 编辑区：`rounded-lg border` + 聚焦环（`focus-within`），工具栏吸附在容器顶部（长文时 `sticky`），最小高度保持。
- 内容排版直接复用 `.content-md` 的同一套样式（标题 / 引用 / 代码 / 表格 / 列表），所见即所得名副其实。
- **表格**：边框与表头底色；光标在表格内时出现**浮动操作条**（上插行 / 下插行 / 左插列 / 右插列 / 删行 / 删列 / 切表头 / 删除表格）；Tab 跳格、末格 Tab 自动加行。

### 2.3 图片插入与附件联动

**核心原则：正文是唯一事实来源，附件面板里的「内嵌图片」是从正文派生出来的视图**，不另存一份状态，所以不存在「两边不同步」。

```mermaid
flowchart LR
  A[工具栏图片按钮 / 粘贴 / 拖入] --> B[选图 / 可选裁剪]
  B --> C[上传 purpose=inline]
  C --> D[编辑区插入图片节点 ![](/files/key)]
  D -->|派生| E[附件面板「内嵌图片」组: 缩略图 + 文件名]
  E -->|删除条目| F[移除正文中所有该 URL 的图片节点]
  D -->|用户在编辑区删图| G[条目随之消失]
  H[附件面板里已上传的图片附件] -->|「插入正文」| D
```

- 附件面板分两组：**内嵌图片**（派生，缩略图，可删除 / 可「在正文中定位」）与**下载附件**（现有逻辑不变，门控归属下拉保留）。
- 删除内嵌图片 = 删正文引用；文件本身由现有孤儿巡检 `db:gc-files` 回收，**不新增删文件路径**。
- 「已上传的图片附件 → 插入正文」：**待 Step 1 核实**服务端 `registerSourceFiles` / `resolveFileGrant` 能否让同一文件既是下载附件又被正文内联引用（涉及图片可见性按引用它的帖子鉴权）。若不能，则「插入正文」= 把该条目从下载组转为内嵌组（同一文件、改登记用途），UI 上对用户表现一致。
- 源码模式同样适用：派生视图从 Markdown 文本解析图片引用，不依赖富文本节点。
- 上传中状态：工具栏图片按钮显示进度，提交按钮禁用的现有机制保留。

### 2.4 门控块更名与交互（只改用户可见名称，不动语法）

**边界**：存储语法 `:::gate{…}`、`getGateContent`、`hidden-md-guard`、迁移转换器、已有帖子**全部不变**（URL / 语法冻结类约定）。「门控」只是内部与文档术语；**用户界面里的名字**可以换，并且只改文案层（工具栏提示、节点视图标题、附件归属下拉、预览占位、设置与通知文案）。

候选名称（站长选一个，我推荐第 1 个）：

| 候选 | 用户视角的话术 | 评价 |
|---|---|---|
| **锁定内容**（推荐） | 「插入锁定内容」「此内容已锁定，回复后解锁 / 支付 50 积分解锁」 | 直白、与锁图标一致，覆盖「回复」与「积分」两种解锁方式 |
| 隐藏内容 | 「回复可见」「积分可见」 | 论坛老用户最熟悉，但「隐藏」偏向屏蔽而非可解锁 |
| 解锁块 | 「解锁块」 | 简短，但新用户不知道是什么 |
| 福利区 / 宝箱 | 「宝箱：回复后开启」 | 有趣、贴合字幕组氛围，但语义不够直白，不利于初次使用 |

块的节点视图改进：标题条显示「🔒 锁定内容」+ 解锁方式分段选择（**回复解锁 / 积分解锁**，取代下拉）+ 价格输入（仅积分）；整体用虚线边框与浅底色，一眼可辨；内部可继续写任意块（含图片）。

### 2.5 移动端快速回复固定条

- 帖子页 `<md` 才出现：**底部 Tab 栏上方**的固定条，形如一个「写下你的回复…」的假输入框 + 发送图标（不是第二个编辑器）。
- 点击：平滑滚到页面底部 `#reply` 区并聚焦编辑器（站长已选定；全页只有一个编辑器实例，草稿 / 附件 / 上传状态零冲突）。
- **与底部回复区互斥**（站长要求）：`IntersectionObserver` 观察 `#reply` 区，进入视口 → 条滑出消失；离开视口 → 滑回。用 `transform + opacity`，时长走 `--fw-dur-*` 令牌，`prefers-reduced-motion` 下无动画（直接显隐）。
- 不可回复的状态（未登录 / 锁帖 / 无权限）：不渲染固定条（与 `replyEntry.mode` 同源判定）；未登录时不出现，沿用现有登录引导。
- 键盘弹起时（`visualViewport`）固定条随回复区聚焦自然隐藏，避免遮挡输入。

### 2.6 回复区与发帖编辑器布局

- 回复区、发帖页、编辑页三处共用同一套 `EditorShell`：统一外框、工具栏吸附、附件区折叠（默认折叠成「附件（N）」一行，展开才见列表），减少首屏被附件占去的高度。
- 「预览」与「切换源码」并入工具栏右侧；预览结果以内联面板显示（保持现有 `/api/preview`）。

## 3. 任务清单（每步结束停下汇报）

1. **实机复现与基线**：逐个点工具栏，记录「点了没反应」的真实清单；对门控块与表格往返做现状测试；核实 §2.3 的服务端待证问题。结论写回本文 §1。
2. **外观 + 工具栏重做**：边框 / 聚焦环 / sticky 工具栏；图标化 + Tooltip + 快捷键；移动端横滚；标题 / 行内代码 / 链接 / 清除格式 / 缩进；去掉无效按钮。
3. **表格完整化**：样式 + 浮动操作条 + 键盘。
4. **图片插入 + 附件联动**：工具栏图片按钮、派生内嵌图片组、双向删除、已有图片附件插入正文、源码模式同样适用。
5. **锁定内容块**：用户可见文案更名（全站检索替换清单先出）、节点视图改版。
6. **回复固定条**：组件 + 互斥动效 + 键盘 / 不可回复态 + E2E（移动项目）。
7. **回复区 / 发帖页布局统一 + 全量门禁**（`pnpm verify:all`、`pnpm test:e2e`）。
8. **收口**：文档、CHANGELOG、站长真机清单。
