# M8 · 互动套件与检索

- 阶段：二·核心 ｜ 覆盖模块：M05 / M06 ｜ 依赖：M6
- 状态：⬜ 未开始

## 目标

社区互动的下半套：点赞、关注、标签、通知中心，加上站内搜索。完成后论坛具备日常活跃的完整互动回路。

## 范围（做什么）

1. **点赞**：主题/回帖点赞（旧 like_count 列已迁）+ 点赞列表弹层 + 通知事件。
2. **关注**：关注用户/版块（旧 nw_attention 4,390 条语义）+ 关注动态聚合页（只聚合新版行为，旧 fresh 流表不迁）。
3. **标签**：主题标签（旧 nw_tag 12 条）+ 版块标签云 + 按标签筛选。
4. **通知中心**：统一通知表（旧 nw_message_notices 32,572 条语义重设计，旧数据不迁）+
   回复/点赞/提及/关注四类通知 + 已读/未读 + 顶栏入口。
5. **搜索**：MySQL FULLTEXT ngram 索引（threads 标题 + content_md、posts content_md）+
   搜索页（分页/版块过滤/时间排序）+ 空结果引导。

## 边界（明确不做什么）

- 不做 Meilisearch（ngram 不敷使用时再立项）；不做私信（M10）。
- 不做推荐流/热搜（无真实需求前不建）。
- 旧点赞/关注明细数据只读参考，不迁移展示（数量小、语义已随主表列迁移）。

## 测试规则

- 单测：通知聚合去重（同一事件多渠道不重复打扰）、关注计数一致性、ngram 查询构造器。
- E2E：点赞→对方收到通知；关注版块→动态页出现新帖；打标签→标签页筛选命中；搜索「刀剣乱舞」「青翼」「字幕组」命中（中日文用例集）。
- 数据边界：is_spam/status 内容不出现在任何搜索与动态结果（专项 E2E）。
