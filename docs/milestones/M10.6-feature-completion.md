## 目标

进入 M11 前把「作为通用论坛程序」缺的管理与账号能力补全：板块管理（含可见性）、基础站点配置、
邀请码管理、账号设置中心与双轨密码、通知偏好，并清账 M10.5 未完成项。

## 范围（四批次，每批独立提交+全门禁）

### 批次 a：板块管理 `/admin/forums`（站长点名）

- `lib/forums/admin.ts`：createForum / updateForum / moveForum（父级迁移）/ deleteForum / 前缀 CRUD，事务内；
  path/depth 重算、移动环检测、删除保护（有主题或有子级 → 拒绝并引导归档）、writeAudit、
  提交后 invalidateAuthzSnapshot()。
- `/admin/forums` 树形列表（分区/版块、排序、可见性徽标、isListed/isArchived、行内操作）+
  `/admin/forums/[fid]` 编辑页（三策略 + isListed/isArchived + 排序 + 父级迁移 + 前缀）。
- 门禁 `site.admin`（LOGO 同判例）；导航入「站点管理」组。

### 批次 b：站点配置 `/admin/settings` + 邀请码 `/admin/invites` + robots/sitemap

- `site.identity {name, tagline}` 新键；lib/site.ts getSiteIdentity()（settings + 常量回退，site-chrome TTL 同口径）；
  消费点：layout metadata、site-header、首页品牌位、mailer 主题与落款。
- `/admin/settings`：身份、注册模式（register.mode）、频控 limits 编辑器（站点级 + 角色常用五字段，
  **只 merge 认识字段**防写坏）；写入全走 setSetting（自带审计）。
- `/admin/invites`：列表/批量生成/撤销未用码 + writeAudit；注册消费逻辑零改动。
- robots.ts + sitemap.ts（可见内容口径，条数上限）。
- 全站默认主题键位**不在本期**（M11 随主题选择落地，避免死配置）。

### 批次 c：账号设置中心 + 双轨密码 + 通知偏好 + 认领完整化（站长点名）

- `/settings` 中心 + `/settings/password`（改密）、`/settings/email`（verify 令牌流）、`/settings/profile`
  （userProfiles 编辑，签名沿用 legacy-html 清洗）、`/settings/notifications`（类型×站内开关）。
- 双轨密码按 [docs/PASSWORD-DUAL-TRACK.md](../PASSWORD-DUAL-TRACK.md) 实施清单：users 两列
  （legacy_password_hash / legacy_password_pending）+ 旧库只读回填脚本 + verify 核验项 +
  verifyLegacyPassword（**先取旧库真实样本校验算法再实施**）+ login 双轨分支 +
  以 legacy_password_pending 为唯一判定源的强制改密引导页 + 设密后哈希置 NULL（四条设密路径全覆盖）。
- 认领/重置成功直接签发会话（按钮「认领并登录」「重置并登录」名实一致）+ 下一步引导 +
  claim 全流程 E2E（现仅可达性测试）。

### 批次 d：打磨清账（M10.5 未完成项全量并入，站长指示）

无 JS 确认回退（GET 确认页）、统一就地 toast、原生控件/EmptyState 收尾、auth 六页 shadcn 化+密码可见性、
HoverCard/积分规则卡/关注筛选、跨路由 VT 专项验收、dotenv 横幅静音（quiet: true）、a11y/Safari 抽查。

## 边界（明确不做什么）

- 不做版块合并/主题批量迁移（删除只允许空版块）；不做角色×版块完整授权矩阵编辑（/admin/authz 已覆盖）。
- 不改权限判定引擎与可见性口径；不动 sessions 表结构（双轨判定源 = users 行）。
- 邀请码不做邮件定向发放（生成+复制自取）；全站默认主题键位留 M11。

## 测试规则

- 单测：path/depth 重算、环检测、删除保护、identity 回退、limits merge、邀请码生成边界、
  verifyLegacyPassword（真实旧样本 fixture）。
- int 测：forums 事务并发（移动/删除竞争）、setSetting 并发、令牌单次消费。
- E2E：forums-admin（restricted 不可见+404、isListed、归档不可发帖、越权）；settings（站点名变化收敛、
  邀请码注册消费）；双轨（旧密码登录→强制改密→旧失效→新直登）；认领自动登录；通知偏好生效。
- 回归：visibility.spec、messages.spec、auth.spec 全绿。
