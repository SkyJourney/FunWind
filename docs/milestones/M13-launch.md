# M13 · 部署与社区重启

- 阶段：三·上线 ｜ 覆盖模块：P4 ｜ 依赖：M9 + M12（全部功能就绪）
- 状态：⬜ 未开始

## 目标

生产部署与社区重启：域名切换、旧 URL 301、备份与监控、老用户邮件召回——四阶段规划的收官。

## 范围（做什么）

1. **生产编排**：`docker/` 生产 compose（nginx + app + MySQL 8.4 + Redis）+ 环境配置分离 + 密钥管理；
   附件目录同步方案（rsync 同布局，静态路由不变）。
2. **旧 URL 301**：phpwind 路由 → 新路由映射表（`read.php?tid=N → /t/N`、`thread.php?fid=N → /f/N` 等），
   依赖 M3 冻结的 URL 格式；nginx 层实现。
3. **备份策略**：MySQL 每日全备 + binlog、附件目录增量、备份可用性演练（恢复到临时实例并抽查）。
4. **可观测**：结构化日志、错误上报（Sentry 或自托管等价物）、基础指标（Uptime/慢查询）。
5. **上线演练**：本地/预发全流程演练（备份→部署→**迁移 v2 全量导入与对账**→301 抽查→回滚预案）。
   **旧库处置**：旧库在 M13 签字前不得删除；上线演练包含旧库完整转储备份（作为最终归档，应用不读取）。
   同时评估历史附件的受限版块鉴权（M5.5 遗留）。
6. **社区重启包**：老用户邮件召回（认领账号链接直达 M4 流程）、邀请码签发工具（admin）、
   首页重启公告（M10 站点框架）。

## 边界（明确不做什么）

- 不做容器编排平台/K8s（单机 compose 符合当前规模）；不做 CDN 与多可用区（后续按流量再议）。
- 不做旧站双写/灰度并存（一次性切换 + 回滚预案）。

## 测试规则

- 演练清单（预发执行并留档）：备份→恢复→`npm run verify` 对账→启动→301 抽查 20 条→回滚→再切换。
- 301 映射：phpwind URL 格式全集用例（含分页/锚点/移动端 simple 路由）E2E。
- 安全走查：生产 Cookie/CORS/headers（CSP 基线）、密钥不入库复查、依赖审计（npm audit 高危清零）。

## 验收门禁

- [ ] 演练全流程两次通过（含一次回滚）
- [ ] 301 用例集全绿；旧帖抽样 20 条直达新页面
- [ ] 备份恢复演练签字；监控告警触达验证（人为制造一次错误）
- [ ] 生产检查单（域名/证书/robots/sitemap/性能预算）逐项通过
- [ ] CHANGELOG 记录；BLUEPRINT 补「上线实录」

## 遗留事项

- 人机验证、Web Push——视重启后社区反馈立项。
- 任务引擎、银行、抽奖、多币种（原「情怀遗珠」）已于 M5.5 决策**取消**，不再立项。
