# M13 · 部署与社区重启

- 阶段：三·上线 ｜ 覆盖模块：P4 ｜ 依赖：M9 + M12（全部功能就绪）
- 状态：⬜ 未开始

## 目标

生产部署与社区重启：域名切换、旧 URL 301、备份与监控、老用户邮件召回——四阶段规划的收官。

## 范围（做什么）

1. **生产编排**：`docker/` 生产 compose（nginx + app + MySQL 8.4 + Redis）+ 环境配置分离 + 密钥管理；
   附件目录同步方案（rsync 同布局，静态路由不变）。
2. **旧 URL 301**：phpwind 路由 → 新路由映射表（`read.php?tid=N → /t/N`、`thread.php?fid=N → /f/N` 等），
   依赖 M3 冻结的 URL 格式；nginx 层实现。
3. **备份策略**：MySQL 每日全备 + binlog、附件目录增量、备份可用性演练（恢复到临时实例并抽查）。
4. **可观测**：结构化日志、错误上报（Sentry 或自托管等价物）、基础指标（Uptime/慢查询）。
5. **上线演练**：本地/预发全流程演练（备份→部署→**迁移 v2 全量导入与对账**→301 抽查→回滚预案）。默认 `pnpm migrate` 在 users 导入后自动执行 `legacy-password` 双轨哈希回填；旧库连接只读，完成后以旧密码登录应进入强制换密页。
   **旧库处置**：旧库在 M13 签字前不得删除；上线演练包含旧库完整转储备份（作为最终归档，应用不读取）。
   同时评估历史附件的受限版块鉴权（M5.5 遗留）。
6. **社区重启包**：老用户邮件召回（认领账号链接直达 M4 流程）、邀请码签发工具（admin）、
   首页重启公告（M10 站点框架）。

## 边界（明确不做什么）

- 不做容器编排平台/K8s（单机 compose 符合当前规模）；不做 CDN 与多可用区（后续按流量再议）。
- 不做旧站双写/灰度并存（一次性切换 + 回滚预案）。

## 测试规则

- 演练清单（预发执行并留档）：备份→恢复→`npm run verify` 对账→启动→301 抽查 20 条→回滚→再切换。
- 301 映射：phpwind URL 格式全集用例（含分页/锚点/移动端 simple 路由）E2E。
- 安全走查：生产 Cookie/CORS/headers（CSP 基线）、密钥不入库复查、依赖审计（npm audit 高危清零）。

## 多实例与规模前置检查单（上线门禁，全项目审查 G-17/G-18）

> 当前实现为**单实例语义**（compose 单 app 容器）。以下清单是多实例 / 规模扩展前的强制核对项，
> 立为上线门禁：任何一项未处置前不得把部署拓扑改为多实例。

1. **进程内限流与计数换共享存储**：请求限流（`lib/auth/ratelimit.ts` 内存 Map）、上传并发闸（`api/upload`）、
   浏览量计数（`lib/views`）——多实例下配额与去重会跨实例失真，须换 Redis / 共享存储（对应 M6-carryover M13-1）。
2. **authz 快照失效通道**：权限快照失效挂在 `globalThis`（`invalidateAuthzSnapshot`），管理动作后其他实例不感知；
   须换共享失效通道（Redis pub/sub 或等价）。
3. **outbox 自愈巡检**：`sweepPending` 由业务流量捎带驱动（单实例语义），多实例下需评估互斥或改定时任务（M13-1 关联）。M11.5 已有进程内调度器与 MySQL 命名锁，迁入是自然落点（见 [定时任务汇总](../SCHEDULED-JOBS.md)），**候选，未做**。
4. **`THEME_PREVIEW_SECRET` 显式一致配置**：缺省为进程随机——多实例下预览 cookie 互不认账，须在环境变量层统一配置。
5. **跨实例缓存收敛窗口**：主题目录 / emoji 面板有 30–60s TTL 缓存，跨实例切换后存在收敛窗口；
   单实例或可接受窗口即记录确认，不可接受则改造失效通道。
6. **G-18 集合规模上限**：启用主题包 ≤5 已在服务层强制（容量事务 + default 行锁，批次 2 落地）；
   上线核对 = 确认部署数据无超额（历史库不会超额，导入器不写 theme_packages），无需额外动作。
7. 其余上线核对项见 `M6-carryover.md` M13-1…M13-7（反向代理请求体上限 / TRUSTED_PROXY_HOPS / 旧会话 /
   孤儿文件 / 对象存储 / HTTP 基准）与本文「验收门禁」。
