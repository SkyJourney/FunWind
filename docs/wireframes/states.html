总览

四态图例

每个页面必须回答四种非常态：加载中 / 空 / 出错 / 权限门控。本页定义全站统一的模式，S5 落地时逐页套用（不再逐页发明）。

① 加载 = 骨架屏（骨架形状 = 真实布局）

落地方式：App Router loading.tsx（列表页/主题页/搜索/私信/通知首屏）——骨架结构必须复用对应页的布局组件，禁止通用转圈。 交互内加载（提交/加载更多）用按钮内 spinner。

② 空态 = 插图占位 + 一句话 + 主行动
没有找到相关主题 换个关键词，或者去版块里逛逛 浏览版块

三要素缺一不可：图标占位（S3 上色时可换插画）、解释性文案（说清「为什么空」）、主行动按钮（把用户推向下一步）。 适用：搜索无结果 / 版块暂无主题 / 无通知 / 无会话 / 关注动态为空（各自的文案在 B2/B3 页面线稿标注）。

③ 出错 = 就地可恢复
! 页面开小差了 错误已记录（ID: 20261027-****），可重试或回到首页
重试 返回首页

落地方式：error.tsx（含 global-error.tsx）+ not-found.tsx 专属 404（同样的插图占位 + 「去搜索/回首页」）。文案保持社区口吻，错误 ID 方便对日志。

④ 门控 = 说明规则 + 给出路径
此处内容回复可见 回复本主题后显示（示意：回复可见态） 回复查看

门控五态沿用现网逻辑（购买/回复可见/登录可见/无权限/过期），S4 只统一视觉：虚线边框 + 斜纹底 + 「规则一句话 + 行动按钮」。404（受限版块/帖子不可见）保持不暴露存在性的现有语义。

补充口径：① 以上四态组件将进入 src/components/（Skeleton 已有，EmptyState / ErrorState 为 S5 新增），业务页禁止手写替代品；② 表单提交失败用 Toaster（sonner 已接）+ 字段级错误回显，不占用本页模式；③ 后台页同样适用（骨架/空态在 B4 线稿标注）。
