B2-私信列表 · 注记（⟦修订⟧ 发起模型，2026-10-27 站长定）
① 不设「发起私信」独立入口：站点没有通讯录/好友概念，独立发起 = 全站用户检索，体验差且是骚扰敞口。私信一律从内容与关系的上下文发起——
└ 帖子/回复的作者行「⋯ 更多」菜单 → 发送私信；
└ 桌面 hover 头像弹出悬浮名片（头像/称号/主题数/关注 + 关注、私信按钮，S5 新组件）；
└ 个人公开页（profile.html）的头卡「✉ 私信」按钮；
└ 通知行、粉丝/关注列表 → 先落对方公开页再发起。
② `/messages?to=uid` 深链保留，作为上述所有入口的统一落点（会话不存在自动建，现网逻辑）。
③ 行点击进入对话（打开即已读）；移动端左滑快捷操作（标记已读/删除，S4 手势定义）。
④ 空态按 states.html 三要素：「还没有私信」+「在帖子或主页里找到TA，点 ✉ 就能聊」+「去首页逛逛」。
⑤ 会话搜索（按会话对方名过滤）列为 S5 增强候选，不阻塞本期。
